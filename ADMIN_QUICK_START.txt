🚀 تشغيل Admin Panel بسرعة على السيرفر
═══════════════════════════════════════════════════════════

📋 انسخ الأوامر دي والصقها في ترمينال السيرفر:

───────────────────────────────────────────────────────────
الطريقة 1: سكريبت تلقائي (الأسهل)
───────────────────────────────────────────────────────────

cd /var/www/mawgood-web
git pull origin main
chmod +x RUN_ADMIN_NOW.sh
./RUN_ADMIN_NOW.sh


───────────────────────────────────────────────────────────
الطريقة 2: أوامر يدوية (إذا السكريبت مش اشتغل)
───────────────────────────────────────────────────────────

# الخطوة 1: الانتقال للمشروع
cd /var/www/mawgood-web
git pull origin main

# الخطوة 2: التحقق من البناء (إذا مش موجود)
cd admin-panel
ls -la dist/index.html

# إذا مش موجود، اعمل build:
cp ../PRODUCTION_ENV_ADMIN.env .env
yarn install --frozen-lockfile
yarn build:preview
cd ..

# الخطوة 3: تشغيل PM2
pm2 delete mawgood-admin
pm2 start ecosystem.config.js --only mawgood-admin
pm2 save

# الخطوة 4: التحقق
pm2 list
curl -I http://localhost:5173


───────────────────────────────────────────────────────────
🔍 فحص المشاكل الثلاثة
───────────────────────────────────────────────────────────

# 1. هل PM2 شغال؟
pm2 list | grep admin
# لازم يطلع "online"

# 2. هل البورت شغال؟
curl -I http://localhost:5173
# لازم يطلع "200 OK"

# 3. هل البناء موجود؟
ls -la /var/www/mawgood-web/admin-panel/dist/index.html
# لازم الملف موجود


───────────────────────────────────────────────────────────
🆘 حل المشاكل السريع
───────────────────────────────────────────────────────────

# المشكلة 1: PM2 مش شغال
pm2 logs mawgood-admin --lines 50
pm2 restart mawgood-admin

# المشكلة 2: البورت مش شغال
netstat -tlnp | grep 5173
# إذا مفيش حاجة، يبقى PM2 مش شغال

# المشكلة 3: البناء مش موجود
cd /var/www/mawgood-web/admin-panel
yarn build:preview


───────────────────────────────────────────────────────────
✅ بعد التشغيل
───────────────────────────────────────────────────────────

افتح المتصفح: http://admin.mawgood.cloud

إذا اشتغل، ثبت SSL:
sudo certbot --nginx -d admin.mawgood.cloud

═══════════════════════════════════════════════════════════
