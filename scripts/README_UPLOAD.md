# دليل رفع المنتجات - Mawgood Product Uploader

## نظرة عامة
هذا السكريبت يقوم برفع المنتجات من ملفات Excel إلى قاعدة البيانات الخاصة بـ Medusa Admin Panel.

## المتطلبات

### 1. تشغيل الـ Backend
تأكد من أن الـ backend يعمل على المنفذ 9000:
```bash
# في مجلد الـ backend
npm run dev
```

تحقق من أن الـ backend يعمل:
```bash
curl http://localhost:9000/health
```

### 2. تثبيت المكتبات المطلوبة
```bash
pip install pandas openpyxl requests
```

## ملفات Excel المطلوبة
يجب أن تكون ملفات Excel موجودة في المجلد: `data-products/`

الملفات المطلوبة:
- H-I-X.xlsx
- H&S.xlsx
- Rehab Lafy.xlsx
- مصنع E-S-H.xlsx

## بنية البيانات المطلوبة في Excel

كل ملف Excel يجب أن يحتوي على الأعمدة التالية:

| العمود | الوصف | مطلوب؟ | مثال |
|--------|-------|--------|------|
| CODE أو Code | كود المنتج الفريد | ✅ نعم | HIX001 |
| وصف المنتج | اسم/وصف المنتج | ✅ نعم | بوليفار قطن تلبيس |
| الصنف | نوع المنتج | ✅ نعم | تيشرت |
| اللون | الألوان المتاحة (مفصولة بـ ● و \n) | ⚠️ اختياري | ابيض●\nاسود● |
| المقاس | المقاسات المتاحة (مفصولة بـ \n) | ⚠️ اختياري | M\nL\nXL\nXXL |
| السعر بالجنيه | السعر بالجنيه المصري | ✅ نعم | 290 |
| السعر بالريال | السعر بالريال السعودي | ⚠️ اختياري | 100 |
| صوره المنتج 1-5 | روابط الصور | ⚠️ اختياري | - |

## ماذا يفعل السكريبت؟

### 1. المصادقة (Authentication)
- يقوم بتسجيل الدخول باستخدام بيانات الأدمن
- يحصل على token للمصادقة

### 2. حذف المنتجات القديمة
⚠️ **تحذير**: يقوم بحذف **جميع** المنتجات الموجودة في قاعدة البيانات

### 3. رفع المنتجات الجديدة
- يقرأ كل ملف Excel
- يحول البيانات إلى الصيغة المطلوبة للـ API
- يرفع كل منتج مع variants (الألوان والمقاسات)

## معالجة البيانات

### الألوان والمقاسات
السكريبت يقوم بـ:
- تحويل الألوان والمقاسات إلى Options
- إنشاء Variants لكل تركيبة (لون × مقاس)
- مثال: إذا كان المنتج له 3 ألوان و 4 مقاسات = 12 variant

### الأسعار
- يستخدم السعر بالجنيه إذا كان موجوداً
- إذا لم يكن موجوداً، يحول السعر من الريال (1 ريال = 13 جنيه)
- يحول السعر إلى cents (× 100)

### الحقول المفقودة
السكريبت يقوم بملء الحقول المفقودة:
- إذا لم يكن هناك عنوان: يستخدم "الصنف + الكود"
- إذا لم تكن هناك ألوان/مقاسات: ينشئ variant افتراضي
- إذا لم يكن هناك سعر: يستخدم 100 جنيه كسعر افتراضي

## متطلبات الـ Admin Panel

حسب schema الـ Admin Panel، كل منتج يجب أن يحتوي على:

### حقول مطلوبة:
- ✅ title (العنوان)
- ✅ status (published/draft)
- ✅ discountable (true/false)
- ✅ options (على الأقل option واحد)
- ✅ variants (على الأقل variant واحد)

### حقول اختيارية:
- subtitle (العنوان الفرعي)
- handle (المعرف الفريد في الـ URL)
- description (الوصف)
- categories (التصنيفات)
- tags (الوسوم)
- material (المادة)
- origin_country (بلد المنشأ)
- images (الصور)

## استكشاف الأخطاء

### خطأ في المصادقة
```
✗ Authentication failed: 401
```
**الحل**: تأكد من صحة البريد الإلكتروني وكلمة المرور

### خطأ في الاتصال
```
✗ Error: Connection refused
```
**الحل**: تأكد من أن الـ backend يعمل على http://localhost:9000

### خطأ في البيانات
```
✗ HTTP 400: Validation error
```
**الحل**: تحقق من أن البيانات في Excel صحيحة ومكتملة

### خطأ في القراءة
```
✗ Error reading file
```
**الحل**: تأكد من أن ملفات Excel موجودة في المجلد الصحيح

## الإحصائيات

## ملاحظات مهمة

1. ⚠️ **النسخ الاحتياطي**: احفظ نسخة احتياطية من قاعدة البيانات قبل التشغيل
2. 🔒 **الأمان**: لا تشارك بيانات الدخول
3. ⏱️ **الوقت**: قد يستغرق رفع جميع المنتجات عدة دقائق
4. 🔄 **إعادة التشغيل**: يمكن إعادة تشغيل السكريبت في أي وقت
5. 📝 **السجلات**: راجع الأخطاء في نهاية التشغيل
